# Ei Chaw Myint Mo — Portfolio 2026

A single-page, responsive portfolio built from the Figma file
**Mo Social Media Portfolio → V4 — The Showcase**.

## Stack

Plain HTML, CSS and vanilla JS. The homepage is one hand-written file; the
case-study and article pages are generated by a small script with no
dependencies.

```
index.html            the homepage (markup, styles, script)
data/work.js          all project content: read by the homepage and the build
content/insights/     one Markdown file per article
build.mjs             generates work/, insights/, sitemap.xml and robots.txt
work/<name>/          generated case-study pages (do not edit by hand)
insights/             generated article pages (appears once an article exists)
assets/site.css|js    styles and behaviour shared by the generated pages
assets/               hero images, portrait, self-hosted fonts
videos/               web-optimised MP4s (H.264, 720p, faststart)
videos/posters/       one JPG poster per video
Supporting Videos/    raw source footage: git-ignored, not deployed
```

## Run locally

```bash
node build.mjs                 # regenerate the pages after any content change
python3 -m http.server 3000    # then open http://localhost:3000
```

The generated pages are committed, so Vercel needs no build step.

## Editing content

**Projects** live in `data/work.js`. Each entry has the title, tagline,
overview, idea, what-I-did list, three headline numbers and its chapters. A
chapter has a title, a paragraph, a short fact list and its films. Change the
file, run `node build.mjs`, commit.

- Swap a hero image: replace `assets/hero-*.jpg` (1500×1000 or larger).
- Add a film: put `name.mp4` in `videos/` and `name.jpg` in `videos/posters/`,
  then add `['name','Label']` to a chapter's `v` list (`['name','Label',1]`
  for a 16:9 film).

**Articles** are Markdown files in `content/insights/`. Copy `_example.md`,
rename it without the underscore (the file name becomes the address), fill in
the header and the text, then run `node build.mjs`. Files starting with `_` are
never published. The Insights link appears in the navigation as soon as one
article exists.

**Moving to a new domain:** change `SITE` at the top of `build.mjs` and run the
build once. It updates every page, the homepage tags, the sitemap and
`robots.txt`.

Hero phrases and their colours are the `HERO` array in `index.html`.

### Encoding new videos

```bash
ffmpeg -i input.mp4 -vf "scale=-2:1280" -c:v libx264 -preset medium -crf 22 \
  -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart videos/name.mp4
ffmpeg -ss 1.5 -i videos/name.mp4 -frames:v 1 -vf "scale=720:-2" -q:v 4 videos/posters/name.jpg
```

## Deploy

Static site — push to GitHub and import in Vercel (framework preset: Other,
no build command), or run `vercel` in this folder.
